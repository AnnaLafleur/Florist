# 🌸 Florist — Interactive Bouquet Builder Website

**Florist** — это интерактивный динамический сайт-конструктор, который позволяет создавать букеты цветов онлайн с помощью специального макета. Основная цель проекта — предоставить пользователям удобный инструмент для визуализации флористических дизайнов с помощью практичных в использовании шаблонов. На веб-сайте доступно многообразие вариантов цветов и зелени, наиболее часто используемых во флористике, а также присутствует большой выбор флористической бумаги, коробок и лент для создания индивидуального дизайна упаковки. Собрать букет можно буквально за несколько минут, после чего будет доступно его скачивание или копирование в формате фотографии — это позволяет удобно использовать получившийся результат для дальнейших целей: например, при обращении к флористу с просьбой собрать букет вашего индивидуального дизайна. Сервис Florist предоставляет возможность неограниченно экспериментировать в флористическом дизайне, а также удобно делиться своими идеями с другими людьми.

Дизайн сайта выполнен с использованием множества различных динамических эффектов, в том числе главной особенностью сайта является 3D-визуализация всех используемых в нём медиа  — это создаёт общность в дизайне и позволяет создать букет в 3D-визуализации посредством 2D-интерфейса.
